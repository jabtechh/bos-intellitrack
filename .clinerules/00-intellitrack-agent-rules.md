# IntelliTrack Cline Rules

Read `AGENTS.md` before material work.

For product changes, use the active spec under `specs/` and the project constitution under `.specify/memory/constitution.md`.

Do not skip directly from a vague request to implementation. Inspect first, map to requirements, and stop for human approval when scope, authorization, database, migration, production, or major information architecture changes are involved.

Never treat existing code as proof that a feature is required.
