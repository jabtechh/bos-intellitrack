# /speckit-tasks

1. Read the approved spec, plan, and checklist.
2. Create/update `tasks.md` using `.specify/templates/tasks-template.md`.
3. Break work into small dependency-ordered tasks.
4. Each implementation task must reference acceptance criteria, requirement IDs, or an approved decision.
5. Include explicit verification tasks for authorization, roles, responsive UI, tests, and convergence.
6. Put migration/deploy/push work behind explicit human-approval tasks.
7. Do not implement automatically.
