# /speckit-plan

1. Read the approved/clarified spec, `AGENTS.md`, and relevant architecture docs.
2. Inspect the current implementation and Git diff before planning.
3. Produce/update `plan.md` from `.specify/templates/plan-template.md`.
4. Choose the smallest safe approach that satisfies the spec.
5. Identify authorization, data, migration, responsive UI, test, and rollback impacts.
6. Preserve unrelated uncommitted work.
7. If the plan changes scope or authority, stop for human approval.
8. Do not implement yet.
