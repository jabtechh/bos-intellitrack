# Documents

Documents are private, internship-bound records. Intern uploads enter `Pending review`; Company Representatives and System Administrators may approve them or request replacement. Interns may replace only their own pending or rejected submissions. Replacement uploads a new object first, conditionally updates the record, then removes the previous object. Company Operations uploads are approved on publication. Records are archived rather than hard-deleted.

Interns see only their own internship records. Company Supervisors see records for directly supervised Interns. School Coordinators have read-only school scope, excluding Identification and Medical document categories. Company Representatives have Bo’s Coffee Main Office scope, and System Administrators have operational scope. Every mutation and signed-link lookup repeats authorization.

The private `internship-documents` bucket permits PDF, JPEG, PNG, WebP, DOCX, and XLSX files up to 25 MB. MIME type, extension, and size are validated server-side. Object paths are generated by the server and never rendered. Secure links expire after five minutes.

Version 1 cannot publish company-wide resources independent of an internship because the existing schema requires an internship relationship. It has no audience/visibility, expiration, request, digital-signature, or persistent version-history fields. Tasks and Evaluations are not presented as document attachments.
