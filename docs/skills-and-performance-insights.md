# Skills and performance insights

IntelliTrack derives private internship insights from existing authorized records. No analytics record, score, ranking, or recommendation is persisted.

The current schema contains explicit skill evidence in approved Work Logs and the Intern-maintained Portfolio. These entries are displayed as recorded labels only; they are not treated as verified proficiency or converted into percentages. Finalized Evaluations also contain structured criteria ratings on the existing 1–5 scale and an independently entered overall score from 0–100. IntelliTrack preserves both scales and performs no weighting.

Insights include required and credited hours, remaining hours, attendance days, late arrivals, early departures, approved Work Logs, active/completed/overdue Tasks, a factual Task completion rate when at least one non-cancelled Task exists, finalized Evaluation count and latest result, role-visible Supervisor feedback, and dated activity from eligible records. Draft, rejected, cancelled, voided, private, and out-of-period records are excluded as appropriate.

Interns see only themselves. Company Supervisors see directly supervised Interns. School Coordinators have read-only school scope. Company Representatives and System Administrators see active internships at Bo's Coffee Main Office. Date parameters are validated on the server and do not weaken these scopes.

Version 1 intentionally has no productivity score, ranking, inferred skill, personality assessment, employment or disciplinary recommendation, predictive classification, or AI rating. Empty sections say “Not enough data yet.” Gemini is not used by this module.
