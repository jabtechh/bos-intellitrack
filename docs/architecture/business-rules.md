# Business Rules Reference

This is a navigation aid for agents, not a new requirements document.

## Attendance
- Intern records Time In/Time Out.
- Attendance stores timestamps and evidence required by the approved requirements.
- Attendance is the authoritative source of rendered internship time.
- Normal attendance should remain automatic; review is for exceptions/corrections where the current approved behavior requires it.
- Do not invent biometric identity/liveness claims.

## Work logs
- Intern submits daily work logs and may attach evidence.
- Supervisor review is required by the approved core requirements.
- Work logs do not independently determine rendered internship hours.

## Internship roles
- Supervisor: assigned-intern oversight.
- Coordinator: school-scoped monitoring.
- Representative: normal Bo's Coffee operational management.
- Admin: technical/bootstrap/emergency.

## Required hours
Use `../roles-and-required-hours.md` as the current ownership interpretation.

## Conflict handling
If implementation behavior and the approved requirement text differ, record the discrepancy in the active spec. Do not silently “fix” requirements to match code or code to match a stale document.
