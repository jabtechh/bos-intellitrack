# IntelliTrack Spec Workspace

This repository uses a lightweight, repo-local Spec Kit-style workflow so the existing project can adopt spec-driven development without overwriting current work.

- Project constitution: `memory/constitution.md`
- Templates: `templates/`
- Active feature specs: `../specs/`
- OpenCode commands: `../.opencode/commands/`

The official Spec Kit CLI is not required to use these files. If the official CLI is installed later, review its generated diff before replacing or merging these repo-local workflows.
